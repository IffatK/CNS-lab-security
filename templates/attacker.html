Interpretation
Protection off: the browser sends a readable lab payload over HTTP, so the monitor records its content. Protection on: the browser encrypts the body with AES-GCM and wraps the key using ElGamal before sending; the monitor records ciphertext metadata only. This protects against a passive network observer, not the server itself. It does not track unrelated websites or other apps.

CNS Secure Lab · Isolated VirtualBox network only · Educational demonstration, not a production cryptographic protocol.
